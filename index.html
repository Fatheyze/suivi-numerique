Ce que dit le texte sur l'IMP

Circulaire n° 2015-058 du 29 avril 2015, point II-6 : la mission de référent pour les ressources et usages pédagogiques numériques est rémunérée par une IMP au « taux annuel de 1 250 € à 3 750 € en fonction de la charge effective de travail et du niveau d'expertise requis ». La circulaire prévoit aussi, pour cette fonction, la possibilité d'un allègement de service.

Synchroniser mes appareils (GitHub)

Vos saisies sont enregistrées dans le fichier « suivi-numerique.json » de votre dépôt privé « donnees-outils », comme vos autres outils : tous vos appareils se mettent à jour tout seuls. Si vous avez déjà connecté un autre de vos outils sur ce navigateur, la clé est reprise automatiquement. Elle n'est jamais écrite dans la page publique.

Paramètres avancés

Signalements des collègues

Donnez à vos collègues un lien, ou un QR code, vers un formulaire « Signaler un problème numérique ». Chaque signalement arrive tout seul dans votre journal en « À faire », déjà rempli, et une alerte peut arriver sur votre téléphone. Les signalements sont chiffrés : vous seul pouvez les lire.

1. Le lien à donner à vos collègues

Voir le formulaire

À envoyer par mail à l'équipe, ou à afficher en salle des profs (clic droit sur le QR code pour l'enregistrer en image).

Dans l'ENT (page « Ticket numérique »)

Dans votre page de l'ENT, cliquez sur l'icône « </> » en haut à droite, choisissez « Code HTML », collez le code, puis revenez en « Éditeur de texte » et enregistrez.

Commencez par la version bouton : elle marche partout. La version intégrée affiche le formulaire directement dans la page, si l'ENT accepte ce type de contenu.

2. L'alerte sur votre téléphone

  1. Installez l'application gratuite ntfy (Android ou iPhone).
  2. Touchez « + » et collez ce nom de sujet :
  3. Laissez le serveur proposé (ntfy.sh) et validez. Faites un signalement de test pour vérifier.

L'alerte indique seulement le type de problème, la salle et l'urgence, jamais le nom du collègue ni la description.

3. Ne rien perdre, même pendant les vacances

Le relais qui transporte les signalements ne les garde que quelques heures. Une copie automatique, toutes les heures, les range dans votre dépôt privé « donnees-outils » (fichier signalements.json, illisible sans votre clé).

Créer la copie automatique sur GitHub

Sur la page GitHub qui s'ouvre, le fichier est déjà rempli : cliquez sur « Commit changes… », puis sur « Commit changes ». À faire une seule fois.
